## False-green controls and limitations

Renaming exported `GEN_INHA` to `BROKEN_GEN_INHA` caused normal `python3 verify_exports.py` to fail with U1.32/J4.1 mismatches (exit 1). **The identical poisoned input under `python3 -O` exited 0** because the verifier uses assertions. Original bytes were restored. This is a confirmed fail-open verification defect: do not run this checker optimized or treat its success as a release gate. Replace assertions with explicit failures and add normal/optimized negative-control tests before promoting the checker to a gate.

The checker imports `generate_schematic`, which rewrites sources/manifest during verification; agreement with its own generated manifest is consistency evidence only. It does not independently establish correct pinout or intended endpoints and does not reject every possible extra node. Freeze independent expectations, check the exact endpoint set and reject duplicate assignments, unexpected nets and missing reports. Count expected ERC exceptions by identity/net, not merely three copies of one error class. Missing/unparseable reports must fail; the separately documented PCB-tooling fail-open must not be inherited.

## Prioritized concrete next circuit changes

1. **Implement independent enable permission, not J11 alone.** Both existing ENABLE nets have 100 kOhm pulldowns, but their only commanding source is an external connector. Add rail-supervised, set-dominant fault memory and a hardware AND permission path for MCU arm, brake loop, rails-good and no fault. Wire both driver nFAULT outputs and an external watchdog through explicitly defined polarities; isolate independent open-drain channels rather than tying push-pull outputs. Prevent reset while any fault persists, and force both enables low on missing safety supply. Connect MCU timer BREAK as a second action, not the only action. ENABLE sleep/reset timing is not a fast short-circuit trip.
2. **Add an autonomous bus sink physically across DC_LINK/PGND.** Currently only provisional capacitors absorb energy. Put comparator/reference/divider/hysteresis, qualified gate driver, low-side chopper FET and dump resistor on a real sheet. Keep this sink active when bridge enable is removed. Calculate thresholds over component tolerance and temperature, then worst-case BMS-opening energy and latency. Both disabled bridges can still rectify through body diodes; “off” is not isolation. A 60 V/7.2 Ohm/5 kJ example is not a resistor selection or descent-energy bound.
3. **Complete protected entry and supply sequencing.** J1 is a connector, not fuse/reverse blocking/precharge/disconnect; J2 is a connector, not a regulator. Select DC-rated interruption, reverse/regen-compatible isolation, precharge bypass and discharge paths, and qualify auxiliary rails under bus rise and brownout. Separate safety-rail availability from MCU rail failure; a chopper that loses its gate supply cannot absorb energy. Bound backfeeding through SPI/ADC/ENABLE during rail sequencing.
4. **Close driver/CSA/OCP configuration and fast current shutdown.** Six 2 mOhm shunts and SP/SN connections are real; hardware external comparator/latch is not. Select driver OCP threshold/deglitch, gate-current settings, PWM mode and CSA gain/reference configuration with readback/re-arm behavior. Add independently justified fast trip and analog input conditioning; define six shunt Kelvin returns despite their present shared PGND logical net. At 30 A the ideal shunt dissipation is 1.8 W, not a qualified continuous rating.
5. **Place the actual MCU and protection/sensor interfaces.** Existing CSV allocation is not connected circuitry. Add six PWM inputs per bridge, SPI chip selects/fault monitoring, six CSA ADC channels, bus voltage/current, thermal and position sensing, reset/debug/decoupling. Verify trigger routing, settling/blanking windows and offboard cable protection; arithmetic ADC conversion time excludes these effects.
6. **Qualify component geometry and stress before PCB work.** Driver footprint missing; passives/connectors largely unselected. Resolve MOSFET Q5B land geometry, thermal pad, commutation-loop inductance, gate-loop parasitics, capacitor bias/ripple and connector currents. The reported `vm_static_margin_V=75-58.4` is a legacy direct-bus hypothetical, **not the actual external-12-V VM margin**; amend that field/report before using it for any design decision. VDRAIN/MOSFET stress must independently include ringing and BMS disconnect.

These are concrete open circuit changes, not implemented protections. Repeat independent schematic and threshold review after each coherent increment. No route/fabricate/energize transition is authorized by publication of this milestone.
